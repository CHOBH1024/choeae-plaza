검색 결과와 감상 안내를 구분합니다

최신 영상과 검색 결과는 외부 서비스가 제공하는 목록입니다. 이름이 같은 사람, 커버 영상, 팬 편집본이 함께 나올 수 있으므로 제목과 업로더를 확인하세요. 검색 결과의 첫 번째 항목을 공식 영상이나 추천 영상으로 인증하지 않습니다.

가수별 감상 길잡이는 최애광장이 작성한 편집 콘텐츠입니다. 곡의 공개 버전과 확인한 출처를 바탕으로 무엇을 비교하며 들으면 좋을지 제안합니다. 감상 순서는 편집 의견이며 공식 추천이나 인기 순위가 아닙니다. 모든 가수에게 개별 길잡이가 준비된 것은 아닙니다.

인기도와 최신순의 범위

조회수 순위는 수집된 최근 영상 안에서 비교합니다. 아티스트의 전체 영상, 모든 플랫폼의 이용량, 음원 차트를 합친 순위가 아닙니다. YouTube 검색의 최신순은 검색 결과에 포함된 영상의 게시 시각을 기준으로 하며 수집 지연과 API 제한이 있을 수 있습니다.
